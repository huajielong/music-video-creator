# Music Video Creator

> AI-powered music video creation skill for [Claude Code](https://claude.ai/code). Generate vocals/instrumentals, create storyboards, batch produce images/videos, and assemble final MV.

## Features

- **Music Generation** — Compose songs with lyrics or instrumentals via Tunee API (Mureka, MiniMax, Lyria, Tempolor, ACE-Step)
- **Storyboard Creation** — Auto-generate shot-by-shot storyboard from lyrics with cinematic prompts
- **Batch Image Generation** — Produce storyboard frames via Doubao Seedream (2560×1440, no watermark)
- **Batch Video Generation** — Turn frames into video clips via Doubao Seedance (720p, 24fps)
- **Subtitle Generation** — SRT files with timing estimated from lyrics and audio duration
- **Multi-language** — CJK-optimized models for Chinese, English, Japanese, Korean, and more

## Quick Start

```bash
# 1. Install dependencies
pip install requests playwright
playwright install chromium

# 2. Configure API keys
export TUNEE_API_KEY="your-tunee-api-key"
export ARK_API_KEY="your-ark-api-key"

# 3. List available music models
python scripts/list_models.py

# 4. Generate a song with lyrics
python scripts/generate.py \
  --title "My Song" \
  --prompt "pop, female vocal, energetic" \
  --lyrics "[Verse 1]\nYour lyrics here..." \
  --model mureka_v9

# 5. Download the MP3
python scripts/download.py --id <music_id>

# 6. Generate SRT subtitles
python scripts/gen_srt.py \
  --lyrics "[Verse 1]\nYour lyrics..." \
  --duration 155 \
  --output output/subtitles.srt

# 7. Create storyboard
python scripts/gen_storyboard.py \
  --title "My Song" \
  --style "cinematic, wuxia, chinese aesthetic" \
  --lyrics "[Verse 1]\n..." \
  --output output/storyboard.md

# 8. Batch generate images (no watermark)
python scripts/batch_generate_images.py --watermark false

# 9. Batch generate videos
python scripts/batch_generate_videos.py --shots 1-30
```

## Scripts

| Script | Purpose |
|--------|---------|
| `generate.py` | Generate music via Tunee API (lyrics or instrumental) |
| `list_models.py` | List available music generation models |
| `credits.py` | Check Tunee account balance |
| `download.py` | Download MP3 from Tunee share page (handles CDN hotlink protection) |
| `gen_srt.py` | Generate SRT subtitles from lyrics with timing estimation |
| `gen_storyboard.py` | Generate storyboard markdown from lyrics, export image prompts |
| `batch_generate_images.py` | Batch generate storyboard images via Doubao Seedream |
| `batch_generate_videos.py` | Batch generate storyboard videos via Doubao Seedance |
| `assemble.py` | Assemble final MV: concat videos + overlay audio + burn subtitles (requires FFmpeg) |

## API Configuration

| Service | Env Key | Description |
|---------|---------|-------------|
| Tunee (music) | `TUNEE_API_KEY` | Music generation API ([tunee.ai](https://www.tunee.ai)) |
| Doubao (image/video) | `ARK_API_KEY` | Volcengine Ark for Seedream (image) & Seedance (video) |

## Lyrics Structure

| Section | Lines | Notes |
|---------|-------|-------|
| Verse | 2, 4, or 8 | Narrative verses |
| Pre-Chorus | 2-4 | Build-up tension |
| Chorus | 4-8 | Hook, repeated |
| Bridge | 2-4 | Climax, once before final Chorus |
| Intro/Outro | — | Instrumental bookends |

## Roadmap

### Short-term
- [ ] **Video assembly script** — Concatenate video clips + audio + subtitles → final MP4 (via FFmpeg)
- [ ] **Precise SRT timing** — Analyze audio waveform for accurate line-level timestamps instead of character-count estimation
- [ ] **Retry mechanism** — Auto-retry failed image/video generations

### Medium-term
- [ ] **Prompt templates** — Pre-built cinematic style packs (e.g., wuxia, sci-fi, romance, horror)
- [ ] **Shot variety optimization** — Detect duplicate prompts across repeated sections and diversify automatically
- [ ] **Model fallback** — If primary model fails, try secondary model automatically

### Long-term
- [ ] **Web UI** — Simple Gradio/Streamlit interface for non-CLI usage
- [ ] **Multi-song album mode** — Generate a series of music videos in batch
- [ ] **Community style gallery** — Shareable storyboard prompt packs
